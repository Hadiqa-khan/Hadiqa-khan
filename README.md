### Hi, I'm Hadiqa

I'm an application security engineer based in Karachi. Most of my work is reading code, breaking web apps and APIs, and then helping the developers who own them fix the root cause so the same bug doesn't come back next sprint.

I was the first security hire at ByteCorp Technologies, so I got to build things from nothing. I did white-box and black-box testing on 15+ web apps and APIs (40+ critical and high findings, including broken access control, IDOR and auth bypasses). I also got Semgrep, CodeQL and Snyk running in CI/CD across most of our repos, ran threat modeling sessions with dev teams, and spent more time than I'd like to admit on SOC 2 evidence.

Lately I've been most interested in what happens to security when a lot of the code is written by AI. I built an AI-assisted assessment tool that took our first-pass reviews from about a week down to a few hours, and a growing part of my code reviews is AI-generated code. Expect some of that to show up here.
